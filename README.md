# MAX Архив

Расширение для сохранения переписки из [веб-версии MAX](https://web.max.ru/) на компьютер.

Проект [Just Trust Digital](https://justtrust.digital). Тестовая версия **0.3.20**. Неофициальное расширение, не связано с разработчиками MAX.

[Скачать расширение](https://github.com/just-trust-digital/max-chat-archive/releases/tag/v0.3.20) · [Сообщить о проблеме](#сообщить-о-проблеме) · [Известные проблемы](KNOWN_ISSUES.md)

## Возможности

- Экспорт текущего чата, выбранных или всех найденных чатов.
- HTML для просмотра переписки, JSON, CSV и TXT для обработки данных.
- Выбор периода, фотографий, видео, голосовых сообщений и других вложений.
- Сохранение в ZIP или папку, отдельно по чатам или общим архивом.
- Список участников групп, реакции, пересылки и необязательное обезличивание контактов.

## Установка в Chrome

1. Скачайте ZIP из [раздела Releases](https://github.com/just-trust-digital/max-chat-archive/releases) и распакуйте его в постоянную папку.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `MaxExport` из архива. В ней должен лежать `manifest.json`.
4. Откройте [web.max.ru](https://web.max.ru/) и войдите в аккаунт. Если вкладка уже открыта, обновите её.
5. Через значок пазла Chrome откройте **MAX Архив**.

В ZIP есть краткая инструкция **START-HERE.pdf**. Папку установленного расширения нельзя удалять или перемещать.

Поддерживаются проверка обновлений и скачивание новой версии из меню расширения.

## Как сохранить переписку

Для одного чата откройте его в MAX и нажмите **Экспортировать открытый чат**.

Для нескольких чатов, выбора периода и вложений откройте **Настройки и выбор чатов**, задайте параметры и нажмите **Скачать ZIP**. Пустые даты означают весь период. Для просмотра вложений без интернета выберите **Файлы вместе с перепиской**.

**Во время экспорта держите вкладку MAX открытой и видимой.** Не переключайте чаты и не обновляйте страницу. Остановить экспорт можно кнопкой **Остановить**.

Распакуйте ZIP и откройте `index.html` в корне архива, затем выберите чат. Переписка находится в `messages.html`; оставьте структуру папок без изменений, чтобы вложения открывались. Итоги и пропущенные файлы перечислены в `report.json`.

## Если экспорт прервался

В разделе **История экспорта** нажмите **Скачать сохранённое**, чтобы получить уже собранную часть переписки. Для получения недостающих сообщений и файлов запустите новый экспорт.

## Ограничения

- Расширение сохраняет только данные, доступные в веб-версии MAX. Изменения интерфейса могут повлиять на работу; проверяйте результат и отчёт.
- Скрытые сообщения, недоступные вложения и скрытые контакты участников не экспортируются.
- Экспорт может помечать сообщения прочитанными.
- По умолчанию — до 25 МБ на файл и 250 МБ на архив или папку. Лимиты можно изменить в настройках. Большие ZIP требуют больше оперативной памяти.

При включённом параметре **Обезличенные контакты** в архиве скрываются имена отправителей, источники пересылок и список участников. Текст сообщений, упоминания, названия чатов и файлов не очищаются.

## Сообщить о проблеме

Нажмите **Напишите нам** внизу меню или настроек. Опишите проблему или предложение; контакт для ответа необязателен. При необходимости добавьте скриншоты, предварительно скрыв переписку и личные данные. Проверьте обращение и подтвердите отправку.

Отправляются ваш текст, указанный контакт и технические сведения из раздела **Данные обращения**. Скриншоты прикладываются только по вашему выбору и с отдельным согласием. Переписка, файлы экспорта и названия чатов автоматически не прикладываются. Обращение и приложения доступны команде проекта, в GitHub они не публикуются.

## Использование с вашим LLM

В пакет включён [скилл для вашего LLM](skills/max-archive/SKILL.md): передайте ему папку `MaxExport/skills/max-archive/` из установочного ZIP. Скилл помогает экспортировать переписку и разбирать локальные JSON с проверкой пропусков. Для управления расширением LLM нужен доступ к тому же браузеру; без него можно работать с уже скачанным архивом.
