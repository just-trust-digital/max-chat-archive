# MAX Архив

Расширение Chromium для локального сохранения переписки из [веб-версии MAX](https://web.max.ru/). Данные обрабатываются в браузере; серверов проекта нет.

## Установка

1. Скачайте или клонируйте этот каталог.
2. Откройте `chrome://extensions` (или `edge://extensions`), включите режим разработчика и выберите **Загрузить распакованное расширение**.
3. Укажите каталог `MaxExport`, откройте `https://web.max.ru/` и войдите в свой аккаунт.
4. Откройте чат и нажмите значок расширения. **Экспортировать открытый чат** запускает сохранение с настройками по умолчанию; **Настройки и выбор чатов** открывает отдельную страницу.

В расширенном режиме можно выбрать открытый чат, несколько чатов либо все найденные чаты текущей папки MAX. Есть форматы HTML + JSON, HTML, JSON, CSV и TXT; период, ссылки, реакции, адреса медиа, попытка скачивания вложений и предел сообщений. Результат — ZIP с каталогом на каждый чат и `report.json` с итогами и пропусками.

## Важные ограничения

- Экспорт использует отображаемый интерфейс MAX. Расширение прокручивает чат и список чатов, поэтому вкладку MAX нельзя закрывать или обновлять до окончания. Во время работы интерфейс может переключаться между чатами и помечать сообщения прочитанными.
- «Все найденные чаты» относится к **текущей папке** веб-версии. Для других папок, скрытых и архивных переписок переключите папку в MAX и повторите поиск. Полнота списка отражается в `discoveryComplete` внутри `report.json`.
- Если MAX меняет разметку или не показывает сообщение, вложение, автора либо точную дату в DOM, расширение не может восстановить эти данные. История загружается прокруткой; возможные разрывы и достижение лимитов отмечаются в `report.json`. Поле `complete` означает, что прокрутка достигла верха без обнаруженного разрыва, а не независимое подтверждение серверного числа сообщений.
- Перед чтением истории расширение ждёт появления прокрутки до 3 секунд. Если MAX ещё не подготовил длинный чат, в отчёте будет `scroll_container_not_found` и `complete: false`; такой результат нельзя считать полной историей.
- Фильтр дат распознаёт ISO-дату, `ДД.ММ.ГГГГ`, русские названия месяцев, «Сегодня» и «Вчера». Сообщения с нераспознанной датой сохраняются, чтобы не потерять данные; их число указано в `unknownDates`. Для юридически значимого архива сверяйте результат с исходным чатом.
- Когда веб-версия показывает имя отправителя в заголовке сообщения, экспорт сохраняет его отдельно от текста. Распознанная дата записывается в поле `date` формата `ГГГГ-ММ-ДД` и отображается в HTML, CSV и TXT.
- Вложения загружаются только при наличии прямого HTTPS-адреса на `web.max.ru` или `st.max.ru`; ссылки без прямого файла остаются в метаданных. Предел — 25 МБ на файл, 250 МБ суммарно. Пропуски перечислены в `skippedMedia`.
- На сентябрь 2026 года проект не проверен в авторизованном аккаунте MAX. Проверены структура опубликованного веб-клиента, браузерный макет списка и сообщений, упаковка ZIP и форматы. Перед использованием на важных данных нужен пробный экспорт и сверка количества/содержимого сообщений.

Расширение запрашивает доступ к вкладке MAX и `st.max.ru` для файлов. Оно не считывает токен аккаунта и не вызывает неофициальные серверные методы MAX. Исходный код доступен для проверки до установки.

## Проверка

```powershell
npm test
node --check content.js
node --check export.js
```

Браузерный макет находится в `test/browser-fixture.html`. Его можно открыть в Chrome; результат проверки выводится в элементе `result`.

Для контрольного экспорта создайте тестовый чат с разными типами сообщений, экспортируйте его в HTML + JSON, сравните число и порядок сообщений с MAX, проверьте `report.json` и откройте HTML из распакованного ZIP. Затем проверьте экспорт нескольких чатов и отдельной папки.

Исследование существующих решений и официальных ограничений: [docs/research-existing.md](docs/research-existing.md).
