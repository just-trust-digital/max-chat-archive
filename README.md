# MAX Архив

Расширение Chromium для локального сохранения переписки из [веб-версии MAX](https://web.max.ru/). Данные обрабатываются в браузере; серверов проекта нет.

## Установка

1. Скачайте или клонируйте этот каталог.
2. Откройте `chrome://extensions` (или `edge://extensions`), включите режим разработчика и выберите **Загрузить распакованное расширение**.
3. Укажите каталог `MaxExport`, откройте `https://web.max.ru/` и войдите в свой аккаунт.
4. Откройте чат и нажмите значок расширения. **Экспортировать открытый чат** запускает сохранение с настройками по умолчанию; **Настройки и выбор чатов** открывает отдельную страницу.

В расширенном режиме можно выбрать открытый чат, несколько чатов либо все найденные чаты текущей папки MAX. Есть форматы HTML + JSON, HTML, JSON, CSV и TXT; период, ссылки, реакции, адреса медиа, скачивание доступных вложений и предел сообщений. По умолчанию расширение скачивает отдельный ZIP для каждого чата; можно выбрать один общий ZIP. В каждом ZIP есть `report.json` с итогами, пропусками и версией расширения (`extensionVersion`). Поле `history` у чата содержит число попыток прокрутки, замен панели и параметры последних 20 шагов без текста сообщений. При экспорте нескольких чатов отдельными архивами дополнительно скачивается `max-archive-summary.json`.

В режиме **Выбранные чаты** кнопки **Выбрать всё** и **Снять выбор** меняют отметки сразу во всём найденном списке. Число выбранных чатов видно перед запуском экспорта.

Ход работы показывает число обработанных чатов, состояние каждого чата и текущий этап: подготовка истории MAX, чтение сообщений, получение адресов файлов, загрузка вложений, создание ZIP. Для чтения истории точный процент неизвестен; счётчик показывает найденные сообщения. При загрузке вложений отображается число обработанных файлов. Повторный запуск сбрасывает индикаторы предыдущего экспорта. Кнопка **Остановить** прерывает текущую загрузку файла и останавливает последующие чаты.

## Важные ограничения

- Экспорт использует отображаемый интерфейс MAX. Расширение прокручивает чат и список чатов, поэтому вкладку MAX нельзя закрывать или обновлять до окончания. Во время работы интерфейс может переключаться между чатами и помечать сообщения прочитанными.
- При экспорте выбранных чатов расширение нажимает строку чата и проверяет заголовок, маршрут и выделение в доступном списке. В узком окне MAX убирает список из DOM после открытия переписки; тогда проверка использует заголовок и маршрут. Название берётся отдельно от подписи о числе участников в сети. Изменение предпросмотра сообщения или перерисовка строки не прерывают экспорт. Если пользователь переключил чат во время чтения, экспорт завершается ошибкой без сохранения сообщений другой переписки.
- «Все найденные чаты» относится к **текущей папке** веб-версии. Для других папок, скрытых и архивных переписок переключите папку в MAX и повторите поиск. Полнота списка отражается в `discoveryComplete` внутри `report.json`.
- Если MAX меняет разметку или не показывает сообщение, вложение, автора либо точную дату в DOM, расширение не может восстановить эти данные. История загружается прокруткой, включая панели с отрицательным `scrollTop`; возможные разрывы и достижение лимитов отмечаются в `report.json`. Поле `complete` означает, что прокрутка открыла дополнительные сообщения и достигла края без обнаруженного разрыва, а не независимое подтверждение серверного числа сообщений. Если прокрутка не сдвигается или не открывает новые сообщения, отчёт содержит `scroll_stalled` либо `history_not_expanded` и `complete: false`.
- При объединении соседних участков истории расширение сверяет порядок сообщений. Повторно показанный участок не добавляется в архив ещё раз; участок без подтверждённого пересечения отмечается как разрыв и не выдаётся за дополнительные сообщения.
- Перед чтением истории расширение ждёт появления прокрутки до 3 секунд. Если MAX ещё не подготовил длинный чат, в отчёте будет `scroll_container_not_found` и `complete: false`; такой результат нельзя считать полной историей.
- При чтении расширение сдвигает панель вверх и посылает события `scroll` и `wheel`, в том числе у верхнего края. На каждом шаге оно заново находит панель, чтобы не прокручивать элемент, заменённый MAX при перерисовке. Программные события могут обрабатываться иначе, чем физическое колесо мыши; загрузку всей истории нужно проверять по результату живого экспорта.
- Фильтр дат распознаёт ISO-дату, `ДД.ММ.ГГГГ`, русские названия месяцев, «Сегодня» и «Вчера». Сообщения с нераспознанной датой сохраняются, чтобы не потерять данные; их число указано в `unknownDates`. Для юридически значимого архива сверяйте результат с исходным чатом.
- Когда веб-версия показывает имя отправителя в заголовке сообщения, экспорт сохраняет его отдельно от текста. Распознанная дата записывается в поле `date` формата `ГГГГ-ММ-ДД` и отображается в HTML, CSV и TXT.
- Название архива берётся из заголовка чата без меняющегося счётчика участников «в сети».
- При включённом скачивании расширение нажимает штатные кнопки **Скачать** у файлов, перехватывает созданный веб-версией адрес загрузки и пытается включить файл в ZIP. Фото, видео и аудио с прямыми адресами также загружаются. Поддерживаются HTTPS-адреса в домене `max.ru`, его поддоменах, на `i.oneme.ru`, `fd.oneme.ru` и узлах `maxvd…okcdn.ru`; последние адреса обнаружены в пользовательских архивах MAX. Другие адреса и вложения без доступного URL остаются в метаданных. Предел — 25 МБ на файл и 250 МБ на один ZIP. Каждая загрузка ограничена 30 секундами. Пропуски перечислены в `skippedMedia`. Веб-версия может показывать уменьшенную копию изображения, поэтому разрешение сохранённого файла нужно сверять с оригиналом.
- Проверка в авторизованном встроенном браузере 19 октября 2026 года подтвердила исправление открытия в узком окне. Последующий экспорт остановился на 30 сообщениях с `history_not_expanded`, оставив панель наверху. Один обычный жест прокрутки вверх у этого края загрузил 59 сообщений. Добавленная отправка событий и повторный поиск панели проверены регрессионными тестами; полный экспорт версии 0.2.5 в живом чате ещё не подтверждён. Перед использованием на важных данных сверяйте количество, даты, авторов и вложения с исходным чатом.

Расширение запрашивает доступ к вкладке MAX, доменам `max.ru`, `oneme.ru` и `okcdn.ru` для файлов, а также к API загрузок браузера для сохранения ZIP. На `okcdn.ru` оно принимает только HTTPS-узлы с именем `maxvd` и цифрами. Оно не считывает токен аккаунта и не вызывает неофициальные серверные методы MAX. Исходный код доступен для проверки до установки.

## Проверка

```powershell
npm test
node --check content.js
node --check export.js
node --check download-bridge.js
```

Браузерный макет находится в `test/browser-fixture.html`. Его можно открыть в Chrome; результат проверки выводится в элементе `result`.

Для контрольного экспорта создайте тестовый чат с разными типами сообщений, экспортируйте его в HTML + JSON, сравните число и порядок сообщений с MAX, проверьте `report.json` и откройте HTML из распакованного ZIP. Затем проверьте экспорт нескольких чатов и отдельной папки.

Исследование существующих решений и официальных ограничений: [docs/research-existing.md](docs/research-existing.md).
