# MAX Архив 0.3.20 — тестовая версия

В списке чатов убраны порядковые номера рядом с названиями. Они не означали количество сообщений или непрочитанных.

Варианты «Открытый чат», «Выбранные» и «Все чаты» теперь помещаются в одну строку в обычном окне настроек. В очень узком окне они переносятся без обрезания.
