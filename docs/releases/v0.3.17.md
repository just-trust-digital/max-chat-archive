# MAX Архив 0.3.17 — тестовая версия

После отправки обращения расширение благодарит за отзыв. Адреса выбранных скриншотов теперь видны владельцу в закрытой карточке GlitchTip. Адрес нужно скопировать в браузер; для открытия снимка нужен вход в GlitchTip с доступом к проекту MaxExport. В GitHub изображения не публикуются.

Выбор и отправка снимков остаются добровольными: до двух файлов, с предварительным просмотром и отдельным согласием. Каждый снимок пересохраняется в WebP без метаданных и уменьшается до 160 КБ. Перед выбором закройте на изображении переписку, имена и другие личные данные.

Для обновления скачайте `max-archive-0.3.17-test.zip`, распакуйте папку `MaxExport` поверх установленной версии, перезагрузите расширение на `chrome://extensions` и обновите вкладку MAX. [Подробная инструкция](https://github.com/just-trust-digital/max-chat-archive#readme).

Проверены 110 автоматических тестов, форма в Edge на ширинах 390, 768 и 1280 px в двух темах и доступ к синтетическому снимку через сервер. Экспорт реального аккаунта MAX и физический телефон в этом выпуске не проверялись.
