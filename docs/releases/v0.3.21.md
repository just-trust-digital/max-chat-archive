# MAX Архив 0.3.21 — тестовая версия

Готовится к выпуску; в GitHub Releases ещё не опубликована.

- Уменьшены разрешения расширения. Сохранённые обращения и скриншоты доступны только страницам самого расширения.
- Работа в режиме инкогнито отключена, чтобы переписка и обращения из приватного окна не сохранялись в обычном профиле.
- Усилена проверка адресов вложений. Файлы с перенаправлением на другой адрес теперь пропускаются и перечисляются в `report.json`.
- Добавлено [описание хранения и отправки данных](../../PRIVACY.md), которое входит в установочный пакет.

Для обновления остановите экспорт, замените файлы в прежней папке установленного расширения, нажмите **Обновить** на `chrome://extensions` и перезагрузите вкладку MAX. Не удаляйте установленное расширение, если хотите сохранить настройки и историю экспорта.

Проверки безопасности и сборка пакета выполнены на синтетических данных. Перед публикацией требуется проверка реальных вложений MAX с учётом нового ограничения перенаправлений. Прежние успешные экспорты подтверждены владельцем; изменённый сетевой путь на реальном аккаунте отдельно не проверялся.
