# MAX Архив 0.3.13 — тестовая версия

- Обратная связь доступна по ссылке в футере. На странице обращения можно выбрать тему, открыть список известных проблем и отправить сообщение после согласия. После неожиданного прерывания экспорта расширение предлагает открыть черновик.
- Список известных проблем загружается из [публичного списка](https://github.com/just-trust-digital/max-chat-archive/blob/main/KNOWN_ISSUES.md). Без сети показывается копия из расширения.
- Меню и настройки предлагают скачать ZIP новой версии из GitHub Releases. Установить скачанное обновление нужно вручную.
- В пакет включён [скилл для LLM](https://github.com/just-trust-digital/max-chat-archive/blob/main/skills/max-archive/SKILL.md) с инструкцией по работе с интерфейсом и локальными архивами.

Переписка и файлы экспорта не прикладываются к отчётам. Отправляются только введённый вами текст, необязательный контакт и показанные перед отправкой технические поля. Закрытая или обновлённая вкладка MAX не создаёт отчёт о краше.

Установка: распакуйте ZIP, выберите папку `MaxExport` через `chrome://extensions` → **Загрузить распакованное расширение**, затем обновите вкладку MAX. [Подробная инструкция и ограничения](https://github.com/just-trust-digital/max-chat-archive#readme).

Проверены 103 автоматических теста, визуальные макеты на ширинах 390, 768 и 1280 px в двух темах, а также синтетическая отправка из установленного расширения Edge в отдельном профиле до закрытого приёмника. Полнота экспорта на реальном аккаунте MAX в этом выпуске отдельно не проверялась.
