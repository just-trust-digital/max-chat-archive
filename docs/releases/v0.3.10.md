## MAX Архив 0.3.10

Тестовый выпуск. Новое:

- Корневой `index.html` со списком переписок в каждом экспорте и восстановленном ZIP.
- Сохранение без ZIP: **Способ сохранения → Папка в Загрузках**. Файлы записываются последовательно в новый каталог `max-archive-…`; общий ZIP в памяти не создаётся.
- Период виден сразу, копии называются **История экспорта**, настройки файлов, ссылок и реакций получили пояснения.
- Обновлена одностраничная PDF-инструкция.

Для установки распакуйте приложенный ZIP и загрузите папку `MaxExport` на `chrome://extensions` в режиме разработчика. При обновлении замените файлы в прежней папке, обновите расширение и вкладку MAX.

В режиме папки действует предел 25 МБ на файл, общего предела размера папки нет. Место сохранения определяется настройками загрузок браузера. Восстановление из истории пока создаёт ZIP. Сохранение отдельных файлов проверено тестами с подменой Downloads API и браузерным макетом; полный прогон этого режима на аккаунте MAX и реальная запись Downloads новой версии пока не подтверждены.

83 автоматических теста проходят. Описание и ограничения: [README](https://github.com/just-trust-digital/MaxExport). Проект [Just Trust Digital](https://justtrust.digital).
