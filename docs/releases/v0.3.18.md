# MAX Архив 0.3.18 — тестовая версия

Статус поиска чатов теперь показывает «Ищем чаты MAX…». Доступны текущий чат, выбранные или все чаты. Если список чатов загрузился не полностью, расширение сообщает об этом и отмечает результат в отчёте.

Для обновления скачайте `max-archive-0.3.18-test.zip`, распакуйте папку `MaxExport` поверх установленной версии, перезагрузите расширение на `chrome://extensions` и обновите вкладку MAX. [Подробная инструкция](https://github.com/just-trust-digital/max-chat-archive#readme).
