# MAX Архив: вариант A «Спокойный»

Утверждён владельцем 22.10.2026. Реализация — `export.html`, `popup.html`, `styles.css`; локальный Inter, без внешних запросов шрифтов и UI-зависимостей.

| Фон | #F4F5F8 | #11131C |
| Поверхность | #FFFFFF | #1B1E2C |

Тема следует `prefers-color-scheme`. Заголовок 28 px с увеличенным межбуквенным интервалом, основной текст 14 px, подписи 12–13 px; Inter с локальным variable TTF и поддержкой кириллицы. Радиус панелей 16 px, полей и кнопок 9 px; отступ панелей 22 px (20 на узком экране). Кнопки и поля — минимум 44 px, клавиатурный фокус — видимый контур. Три колонки выше 980 px, две до 980, одна до 700. Поля периода всегда видны.

История — отдельный раздел. Счётчик означает количество сохранённых копий, а подпись этапа — последний записанный этап, не успешное завершение. Переключение разделов блокируется во время работы. Нет кнопки автоматического показа MAX в предупреждении: пользователь переключается вручную.

Стрелка экспорта: внешняя сине-фиолетовая рамка и вложенный светящийся квадрат; внутри симметричная стрелка с округлёнными окончаниями и углами 45°. Иконки 16/32/48/128 и SVG собираются одним скриптом. Для JTD используются исходные SVG для светлого и тёмного фона без перекраски; по правке владельца подпись «Сделано JTD» убрана, ссылка представлена знаком с alt JTD. Обязательный текст показан неактивным чекбоксом с подсказкой по наведению/фокусу. Календарь собственный, русский, неделя с понедельника, обе темы и клавиатура.
