# MAX Архив: вариант A «Спокойный»

Утверждён владельцем 22.10.2026. Реализация — `export.html`, `popup.html`, `styles.css`; без внешних шрифтов и UI-зависимостей.

| Роль | Светлая | Тёмная |
| --- | --- | --- |
| Фон | #F4F5F8 | #11131C |
| Поверхность | #FFFFFF | #1B1E2C |
| Текст | #202534 | #F0F0F7 |
| Вторичный текст | #606B80 | #B7BFD3 |
| Граница | #E0E4EC | #3B4155 |
| Акцент | #563CE4 | #AA9BFF |
| Акцентный фон | #EEEBFF | #30294B |

Тема следует `prefers-color-scheme`. Заголовок 30 px (28 на узком экране), основной текст 14 px, подписи 12–13 px; системный sans-serif. Радиус панелей 16 px, полей и кнопок 9 px; отступ панелей 22 px (20 на узком экране). Кнопки и поля — минимум 44 px, клавиатурный фокус — видимый контур. Три колонки выше 980 px, две до 980, одна до 700. Поля периода всегда видны.

История — отдельный раздел. Счётчик означает количество сохранённых копий, а подпись этапа — последний записанный этап, не успешное завершение. Переключение разделов блокируется во время работы. Нет кнопки автоматического показа MAX в предупреждении: пользователь переключается вручную.

Стрелка экспорта: единая координатная сетка, симметрия вокруг x=64, штрих 9, округлённые окончания, углы 45°. Иконки 16/32/48/128 собираются одним скриптом. Для JTD используются исходные SVG для светлого и тёмного фона без перекраски; подпись «Сделано JTD» входит в ссылку. [Происхождение и хеши](../assets/README.md).
