# Разработка

Расширение Manifest V3 на JavaScript, HTML и CSS, без сборщика и внешних зависимостей во время работы. Версия задаётся в `manifest.json` и `package.json`.

## Проверки

Из корня репозитория (Node.js с поддержкой `node --test`):

```powershell
npm test
node --check content.js
node --check export.js
node --check download-bridge.js
```

На 22 октября 2026 года проходят 76 автоматических тестов. Они проверяют сбор сообщений, даты, вложения, ZIP, форматирование, остановку и восстановление. Это не доказательство полноты истории реального аккаунта MAX.

## Браузерные макеты

Для этого checkout проверен запуск:

```powershell
Set-Location D:\DEV\MaxExport
npm run test:browser
```

На другом компьютере сначала перейдите в свой каталог репозитория. Сервер слушает только `127.0.0.1:8767`, использует синтетические данные и не обращается к MAX. Остановка - `Ctrl+C`; повторный запуск той же командой.

| Проверка | Адрес |
| --- | --- |
| Загрузка истории, лимиты и медиа | http://127.0.0.1:8767/test/stream-fixture.html |
| Настройки и размеры окна | http://127.0.0.1:8767/test/ui-layout.html?width=1280&theme=dark |
| HTML-архив | http://127.0.0.1:8767/test/archive-preview.html |
| Сохранение копии в IndexedDB | http://127.0.0.1:8767/test/checkpoint-fixture.html |
| Восстановление ZIP | http://127.0.0.1:8767/test/export-visibility.html?tab=7&fixture=recovery |

Для макета настроек доступны `width=390`, `768`, `1280` и `theme=light`, `dark`. Перед изменениями интерфейса проверяйте обе темы, длинный текст, ошибки и узкое окно. Принудительный выбор темы действует только в макете; установленное расширение следует системной теме.

Для проверки на реальном аккаунте перезагрузите расширение на `chrome://extensions`, затем вкладку MAX. Экспортируйте тестовый чат с разными типами сообщений и сравните количество, порядок, даты и вложения с оригиналом. Проверьте `report.json` и HTML из распакованного ZIP. Отдельно проверьте несколько чатов. Реальную переписку и отчёты с личными данными в Git не добавляйте.

## Пакет для тестировщиков

На Windows нужны Python, `reportlab`, `pypdf` и системные шрифты Arial. Для установки зависимостей в свою среду:

```powershell
python -m pip install reportlab pypdf
python scripts/package-test-release.py
```

На компьютере владельца проверена готовая среда Codex:

```powershell
Set-Location D:\DEV\MaxExport
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" scripts/package-test-release.py
```

Результаты:

- `output/max-archive-<версия>-test.zip`: устанавливаемая папка `MaxExport` и `START-HERE.pdf`.
- `output/pdf/max-archive-quick-start.pdf`: отдельная инструкция на одной странице.
- `output/max-archive-<версия>-test.zip.sha256`: контрольная сумма ZIP.

Скрипт использует явный список из 13 файлов, включая лицензию, проверяет целостность ZIP и совпадение с исходниками. Профили, переписки, тесты и Git в пакет не входят. После изменения зависимостей расширения обновите список `FILES`. PDF нужно отрендерить и осмотреть перед публикацией; проверка одной страницы и извлечённого текста в скрипте не заменяет визуальную проверку.

Артефакты из `output/` исключены из Git; для распространения прикрепляйте ZIP, PDF и SHA-256 к GitHub Release. При обновлении релиза обновите версию в манифесте и `package.json`, ссылки и номер версии в README, затем пересоберите пакет.

## Устройство

| Файл | Назначение |
| --- | --- |
| `content.js` | Поиск чатов, прокрутка, чтение DOM и получение адресов вложений |
| `download-bridge.js` | Перехват адресов в контексте страницы MAX |
| `export.js` | Настройки, очередь чатов, скачивание и отчёты |
| `checkpoint.js` | Копии сообщений и файлов в IndexedDB |
| `format.js`, `zip.js` | Форматы архива и ZIP |
| `timer-worker.js` | Служебный процесс для ожиданий |

Подробные заметки прошлых проверок: [журнал до 0.3.9](development-history.md). Известные ограничения текущей версии описаны в [README](../README.md).
