# Разработка

Расширение Manifest V3 на JavaScript, HTML и CSS, без сборщика и внешних зависимостей во время работы. Версия задаётся в `manifest.json` и `package.json`.

## Проверки

Из корня репозитория (Node.js с поддержкой `node --test`):

```powershell
npm test
node --check content.js
node --check export.js
node --check download-bridge.js
```

На 22 октября 2026 года проходят 83 автоматических теста. Они проверяют сбор сообщений, даты, вложения, ZIP, форматирование, остановку и восстановление. Это не доказательство полноты истории реального аккаунта MAX.

После выпуска 0.3.9 поля периода вынесены из сворачиваемого блока, раздел копий называется «История экспорта», настройки файлов, ссылок и реакций получили пояснения. Проверены реальные рендеры макета на ширинах 390, 768 и 1280, светлая и тёмная темы, ввод даты и раскрытие истории клавишей Enter. Горизонтального переполнения внутри этих размеров нет. Использованы синтетические данные и iframe, не физический телефон. Снимки: [узкая тёмная тема](max-040-period-dark-390.png), [период и история](max-040-period-light-768.png). Четыре теста `test/download-bridge.test.js` проходят; они проверяют перехват голосовых без вызова настоящего `play()`, но не доказывают отсутствие любого воспроизведения в живом MAX.

## Пакет для тестировщиков

На Windows нужны Python, `reportlab`, `pypdf` и системные шрифты Arial. Для установки зависимостей в свою среду:

```powershell
python -m pip install reportlab pypdf
python scripts/package-test-release.py
```

На компьютере владельца проверена готовая среда Codex:

```powershell
Set-Location D:\DEV\MaxExport
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" scripts/package-test-release.py
```

Результаты:

- `output/max-archive-<версия>-test.zip`: устанавливаемая папка `MaxExport` и `START-HERE.pdf`.
- `output/pdf/max-archive-quick-start.pdf`: отдельная инструкция на одной странице.
- `output/max-archive-<версия>-test.zip.sha256`: контрольная сумма ZIP.

Скрипт использует явный список из 21 файла, включая лицензию, проверяет целостность ZIP и совпадение с исходниками. Профили, переписки, тесты и Git в пакет не входят. После изменения зависимостей расширения обновите список `FILES`. PDF нужно отрендерить и осмотреть перед публикацией; проверка одной страницы и извлечённого текста в скрипте не заменяет визуальную проверку.

Артефакты из `output/` исключены из Git; для распространения прикрепляйте ZIP, PDF и SHA-256 к GitHub Release. При обновлении релиза обновите версию в манифесте и `package.json`, ссылки и номер версии в README, затем пересоберите пакет.

## Вывод в папку (0.3.10)

`directory.js` реализует тот же интерфейс `add`, что и ZIP, и последовательную очередь скачиваний с `flush`. `export.js` передаёт запись в `saveBlob` с `conflictAction: overwrite`: это нужно для обновления собственного `index.html` и отчёта внутри нового каталога с уникальным кодом. Существующие каталоги не выбираются. Нельзя передавать в этот класс произвольный пользовательский корневой путь. Файлы скачиваются относительно Downloads; абсолютные пути, обратные переходы и недопустимые компоненты отвергаются. Описание Chrome: https://developer.chrome.com/docs/extensions/reference/api/downloads .

Выбор произвольной папки через `showDirectoryPicker` не используется: доступность и поведение в расширениях отличаются от обычной страницы. Проверены очередь, вложенные пути, сохранение двух чатов без конструктора ZIP, остановка при ошибке диска и при прерывании скачивания. Браузерный макет: http://127.0.0.1:8767/test/directory-fixture.html ; он проверяет формирование отдельных файлов и байты в памяти браузера, а не реальную запись в Downloads. Для живой проверки загрузите текущую версию расширения, обновите MAX, выберите папку в настройках и сверьте реальные файлы на диске. Такой прогон на аккаунте этой версии пока не подтверждён.

Рендеры нового выбора сохранения проверены на ширинах 390, 768 и 1280, в светлой и тёмной темах. Разбиение ZIP отключено в режиме папки, кнопка называется «Сохранить в папку»; переполнения по горизонтали нет. Снимки: [768](folder-settings-light-768.png), [390](folder-settings-dark-390.png), [макет файлов без ZIP](folder-output-proof.png). Скрипт макетов увеличивает высоту iframe, чтобы новая настройка не обрезала нижние элементы.


## Интерфейс 0.3.11

Утверждён A «Спокойный». Настройки разбиты на чаты/период, содержимое и сохранение; история открывается отдельной вкладкой. При пустом выборе запуск отключён. Выбор «Файлы»/«Внешние ссылки» сохраняет прежний параметр `downloadMedia`, совместимость настроек сохранена. Во время экспорта и скачивания копии навигация между разделами отключена, чтобы кнопка остановки не скрывалась.

[Токены и брендинг](design-system.md). [Источники SVG и сборка PNG](../assets/README.md). Логотипы JTD скопированы без изменения формы и цвета из утверждённого набора. Ссылки JTD и GitHub есть в настройках и popup. Разрешения расширения не расширялись.

Просмотр popup: http://127.0.0.1:8767/test/popup-preview.html?theme=light . Работает той же командой `npm run test:browser`, данные синтетические, кнопки макета не открывают MAX. История и прогресс проверяются через основной макет; `chats=populated` включает три синтетических чата, отсутствие параметра — пустой список.

Браузерная проверка 22.10.2026: 390/768/1280 px в двух темах, длинные названия, пустой выбор, история, ошибка периода, предупреждение видимости MAX, остановка, выбор файлов/ссылок, папка/ZIP и обезличивание. Геометрия и снимки: [ui-0311](ui-0311/README.md). Это проверка интерфейса с подменой API, не подтверждение нового прогона экспорта на реальном аккаунте. Мобильные ширины проверены iframe, физическое устройство не использовалось.
