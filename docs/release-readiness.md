# Перед следующим публичным выпуском MAX Архива

Проверено 25 октября 2026 года. База — опубликованная 0.3.20 (`c29c593`); изменения безопасности оформлены как **0.3.21** в исходниках и локальном пакете. Новый выпуск не опубликован. [Заметки 0.3.21](releases/v0.3.21.md). [Доказательства и границы проверки](release-readiness-evidence.md).

**Реальный экспорт и прежние тесты многократно проверены владельцем.** Это подтверждение принято; повторный полный прогон аккаунта не требовался. Отдельно проверены изменения безопасности на синтетических данных и установленном расширении из ZIP.

1. [x] **Разрешения и границы доступа.** Удалён общий `tabs`; поиск и активация MAX работают по host permission. Контакты и снимки обращений в `storage.local` недоступны content script. Инкогнито явно запрещён. Меняющиеся домены MAX/CDN сохранены; список внутри загрузчика уже манифеста. Обмен с MAIN world не считается доверенным только из-за nonce.
2. [x] **Адреса и содержимое.** Загрузчик отклоняет неожиданные схемы, домены, порты и URL с логином/паролем. Обход через HTTP redirect исправлен и проверен настоящим 302. HTML с вредоносными вставками открыт в Chromium: выполнение кода и сетевые обращения отсутствуют. CSV и пути дополнительно покрыты тестами.
3. [x] **Приватность и сохранённые копии.** Проверены сетевые вызовы и состав payload; браузерная проверка удаления очистила и запись, и файлы IndexedDB. Добавлено [описание данных](../PRIVACY.md), включённое в ZIP. Согласие, повторы и ограничения обращений проходят тесты; серверная конфигурация и закрытый inbox заново не проверялись.
4. [x] **Сканеры и пакет.** Gitleaks не нашёл секретов в истории и распакованном кандидате. Semgrep OSS выполнил 8 согласованных наборов: новых подтверждённых уязвимостей нет; 15 эвристических замечаний разобраны. Два набора и отдельные GitHub Actions-правила имеют ограничения разбора — подробности в доказательствах. pypdf упаковщика обновлена до 6.21.2; четыре закреплённые Python-зависимости проверены OSV. ZIP проверен на CRC, точный состав и совпадение исходных байтов; установлен в чистом Chromium. Синтетический архив с 240 МиБ данных успешно собран; потребление памяти остаётся значительным.
5. [ ] **Перед публикацией 0.3.21.** Проверить на реальном MAX именно вложения, которые могут требовать перенаправления: теперь они пропускаются с записью в `report.json`. Это изменение поведения ещё не проверено на аккаунте владельца. Номер и заметки версии подготовлены; остаётся проверить обновление с опубликованной версии и опубликовать отдельный выпуск с соответствующим тегом и заметками. Не заменять существующий релиз новым пакетом с тем же номером.

Минимальный повторяемый запуск из PowerShell:

```powershell
# Выполните из корня репозитория
npm run check
npm test
```

Прошли 112 из 112 автоматических тестов; проверен синтаксис 44 файлов JS/CJS. Воспроизводимый браузерный аудит и проверенная команда PowerShell описаны в [документации разработки](development.md#проверки). Это ограниченный аудит, не сертификат отсутствия уязвимостей.

Для расширения не нужны автоматически все пункты сайта: 404, sitemap, SEO и рекламные пиксели. При публикации в магазине потребуется отдельная проверка его актуальных требований. Nuclei/Trivy и Android MASTG не являются первым шагом для проверки клиентского экспортёра; сервер приёма обращений проверяется отдельно в разрешённом контуре. Практичный первый набор — скан секретов и анализ JavaScript плюс сценарии выше; сторонние скрипты из закладок без ревью не запускать.
