# Данные в MAX Архиве

MAX Архив сохраняет доступную в веб-версии MAX переписку на вашем компьютере. Расширение не отправляет сообщения и файлы экспорта разработчику автоматически. Рекламной аналитики в расширении нет.

## Что остаётся на компьютере

Настройки, сохранённые копии переписки с загруженными вложениями и черновики обращений хранятся в профиле браузера. Скачанные ZIP и папки находятся отдельно, в выбранном браузером каталоге загрузок. Эти данные не шифруются самим расширением: учитывайте доступ других людей к вашему компьютеру и резервным копиям профиля.

Удалить сохранённую копию можно в разделе **История экспорта**. Это удаляет копию из расширения, но не скачанные файлы; их удаляют отдельно. Удаление расширения удаляет его локальное хранилище браузера, а скачанные архивы остаются на диске.

Расширение не работает в режиме инкогнито. Обезличивание контактов скрывает имена отправителей, источники пересылок и список участников, но не очищает текст сообщений, упоминания, названия чатов и файлов.

## Когда используется сеть

- При экспорте расширение читает открытую страницу MAX и по выбранным настройкам загружает вложения с доменов MAX и его файловых сервисов. Для доступа к файлам браузер может использовать вашу сессию MAX. Экспорт может помечать сообщения прочитанными.
- Если сервер вложения перенаправляет запрос, файл пропускается и отмечается в `report.json`.
- При открытии меню и настроек GitHub получает запрос на проверку новых версий. При открытии списка известных проблем загружается опубликованный список; если сеть недоступна, используется включённая в расширение копия. Переписка и идентификаторы аккаунта в эти запросы не включаются.
- Новая версия скачивается с GitHub после вашего действия. Установка обновления выполняется вами вручную.
- Ссылки на внешние вложения в архиве обращаются к соответствующим сайтам при открытии. Для просмотра без сети выбирайте загрузку файлов вместе с перепиской; недоступные файлы будут перечислены в отчёте.

При сетевом запросе принимающий сервис видит обычные сетевые сведения, включая IP-адрес. Сайты MAX и GitHub обрабатывают их по собственным правилам.

## Обращения в поддержку

Форма **Напишите нам** показывает данные до отправки и требует согласия. Отправляются ваш текст, необязательный контакт, номер обращения, дата, версия расширения, тип обращения и технический код проблемы. Скриншоты включаются только после вашего выбора и отдельного согласия. Расширение не скрывает личные данные на снимках: закройте их перед выбором файла.

Автоматически обнаруженный сбой создаёт локальный черновик. Сам по себе он не отправляется. Локальная очередь хранит до 20 обращений; записи старше 14 дней исключаются при обращении к очереди и удаляются при следующем её сохранении. После успешной отправки байты скриншотов удаляются из локальной очереди; текст и квитанция могут оставаться до очистки очереди. Отмена удаляет неотправленное обращение.

Подтверждённые вами данные отправляются по HTTPS в закрытый приёмник Just Trust Digital и систему GlitchTip. Переписка, архивы, названия чатов, токены и пароли автоматически не прикладываются. Не вставляйте их в текст самостоятельно. Повтор отправки использует прежний номер обращения. Публичный список проблем содержит только проверенные описания без личных данных.

Для вопроса о своём обращении или просьбы удалить его используйте **Напишите нам**, укажите номер и контакт для ответа. Срок автоматического удаления принятого обращения на сервере этим документом не установлен; локальные 14 дней не означают удаление с сервера.
