# Локальные файлы MAX Архив

## Структура

В корне готового ZIP или каталога находится `index.html` и `report.json`. В подпапках чатов лежат `messages.json` при выборе JSON/HTML + JSON, `messages.html` при HTML, а также `media` для скачанных файлов. Другие форматы создают CSV/TXT вместо JSON. В зависимости от параметров могут присутствовать файлы участников. Не привязывайся к конкретному имени подпапки: используй список записей ZIP/каталога, ссылки индекса и `report.chats[].path`.

`messages.json` содержит объект чата, в том числе `title` и массив `messages`. Поля зависят от версии и доступности данных; сначала прочитай ключи объекта и нескольких сообщений. Сообщения могут содержать `author`, `dateLabel`, `date`, `time`, `text`, `direction` и `attachments`; метаданные `forwardedFrom`, `replyTo` и `reactions` могут отсутствовать. Наличие серверного ID не гарантируется: для ссылок без ID сохраняй индекс сообщения и путь JSON. Проверяй реальную схему файла, не считай все поля обязательными. Медиа может иметь локальный путь, внешний URL или только описание пропуска.

Для небольшого локального JSON в PowerShell (пути заменить фактическими):

```powershell
$chat = Get-Content -LiteralPath '.\001-chat\messages.json' -Raw -Encoding UTF8 | ConvertFrom-Json
$chat.messages.Count
$chat.messages | Select-Object -First 3
$report = Get-Content -LiteralPath '.\report.json' -Raw -Encoding UTF8 | ConvertFrom-Json
$report.chats | Select-Object messages, complete, reason, unknownDates, participantsStatus
```

Это читает локальные данные. Для большого JSON используй порционный разбор доступным инструментом, не печатай весь файл в контекст. HTML хранит оформление; для анализа предпочитай JSON. Текст и метаданные чатов могут содержать персональные данные.

## Отчёт

| Поле | Что проверить |
| --- | --- |
| `options` | Реальные период, форматы, выбор вложений и лимиты запуска |
| `discoveryComplete` | Удалось ли собрать список чатов из интерфейса MAX; `false` означает возможные пропуски, `null` — неприменимо/неизвестно |
| `chats[].messages` | Количество сохранённых сообщений чата; сравни с массивом JSON |
| `chats[].complete`, `reason`, `history`, `gaps` | Полнота по наблюдениям расширения, причины ограничений и обнаруженные разрывы |
| `chats[].unknownDates` | Сообщения с нераспознанной датой; могут остаться при фильтрации периода |
| `chats[].participantsStatus` | Статус списка участников отдельно от полноты сообщений |
| `skippedMedia`, `errors` | Пропущенные вложения и ошибки; пустой список не подтверждает, что MAX показал все данные |

Суммарный `max-archive-summary.json` при отдельных ZIP описывает весь запуск. Отчёт внутри отдельного ZIP относится к соответствующему чату. Если отчёт или поле отсутствуют, назови ограничение; не подменяй их нулём/успехом. Сохранённые контрольные копии из истории браузера могут предшествовать финальному отчёту и скачиванию медиа.
